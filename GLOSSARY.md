# Alarm at Game End

Domain language for the game-aware alarm application and its Discord connection.

## Language

**Alarm**:
A named reminder scheduled for a local time, optionally delayed until a tracked game ends.

**Pending alarm**:
An alarm that is scheduled or waiting for a tracked game to end.

**Desktop companion**:
The local alarm application linked to Discord through a Discord bridge.

**Discord bridge**:
The remote application that connects Discord interactions to a desktop companion.

**Discord session**:
The desktop companion's current Discord pairing and access state for its configured Discord bridge.
_Avoid_: Discord account
